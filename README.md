# Passive Attack Surface & Subdomain Mapper

An asynchronous passive reconnaissance tool built in Python that discovers subdomains via Certificate Transparency logs (crt.sh), resolves live IPs, and inspects HTTP/HTTPS headers and titles.

## Usage
```bash
pip install -r requirements.txt
python3 surface_mapper.py
```

## Disclaimer
Use only against domains you own or have explicit permission to assess.
